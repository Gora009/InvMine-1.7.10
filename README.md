# InvMine

Ходьба с открытыми интерфейсами для **Minecraft 1.7.10 (Forge)**. Аналог [InvMove](https://modrinth.com/mod/invmove) для старой версии.

Walk, jump and sprint while inventories, chests, machines and mod GUIs are open. Client-side only.

## Возможности

- Ходьба, прыжок и бег в инвентаре, сундуках, печках, механизмах и интерфейсах модов.
- Пока активно текстовое поле (поиск в креативе, наковальня, NEI, AE2 и др.), клавиши печатают текст, а не двигают игрока.
- Не работает в чате, табличках, книгах, командном блоке, настройках управления, меню паузы.
- Приседание по умолчанию выключено, чтобы не мешать shift-клику.
- Клавиша для быстрого включения/выключения (назначается в настройках управления).
- Настройки в `config/invmine.cfg` или через кнопку Config в списке модов.

## Совместимость

- Нет ASM/Mixin/coremod: мод не меняет код игры и других модов, поэтому не конфликтует с ними.
- Только клиент: на сервер ставить не нужно, можно заходить на любые сервера.
- Нагрузка минимальная: одна проверка за игровой тик.

Если какой-то интерфейс мода ведёт себя неправильно, включите `logScreenClass = true`, найдите имя класса в логе и добавьте его в `blacklist`.

## Установка

Скачайте jar со страницы [Releases](../../releases) и положите в папку `mods`. Нужен Forge 10.13.4.1614 для 1.7.10.

## Сборка

Нужна Java 21 (сам мод компилируется под Java 8):

```bash
./gradlew build
```

Готовый файл: `build/libs/InvMine-1.7.10-<версия>.jar`.
